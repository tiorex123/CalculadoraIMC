# 📊 Calculadora de IMC (Índice de Massa Corporal)

Uma aplicação web simples, moderna e responsiva desenvolvida para calcular o Índice de Massa Corporal de forma rápida e intuitiva, auxiliando no monitoramento da saúde básica.

## 🚀 Funcionalidades

- **Cálculo em Tempo Real:** Insira seu peso e altura para obter o resultado instantaneamente.
- **Classificação Detalhada:** Informa se o usuário está abaixo do peso, com peso normal, sobrepeso ou graus de obesidade, seguindo as diretrizes da OMS.
- **Interface Responsiva:** Design adaptável para funcionar perfeitamente em computadores, tablets e smartphones.
- **Validação de Entradas:** Alertas visuais caso campos obrigatórios estejam vazios ou contenham valores inválidos.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web fundamentais, sem dependências de frameworks pesados:

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização moderna, Flexbox/Grid e design responsivo.
- **JavaScript (Vanilla):** Lógica de cálculo, manipulação do DOM e validações.
